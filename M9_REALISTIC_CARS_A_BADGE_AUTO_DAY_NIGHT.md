# NEON OVERDRIVE M9 — Realistic-style cars and automatic day/night

M9 is an incremental update based on M8.

- Added extra original body details: side skirts, mirrors, side intake slats, front grille, light elements, rear diffuser and metallic wheel details.
- Added a small custom abstract **A** insignia on the hood. It is an original mark, not a copied vehicle manufacturer logo.
- Added an automatic 180-second lighting cycle in the game world: daylight transitions through warm sunset into night and back. Ambient, directional and hemisphere lighting plus sky/fog colours adjust smoothly.
- Retains fictional, unbranded car names and selectable colour/performance profiles. These are more detailed stylized game models, not licensed or photorealistic scans of real cars.
- No external logo or model assets added.

## Run and verify

```bash
npm install
npm run build
npm test
npm run dev
```

The archive can be checked for ZIP integrity, but the current environment may not have the dependencies installed to run a full build or browser gameplay test. Verify the hood emblem placement, car proportions and day/night transitions in the browser after installing dependencies.
